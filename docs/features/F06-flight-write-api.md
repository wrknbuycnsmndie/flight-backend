# F06: API создания и изменения рейсов

**Статус:** Запланировано

## Цель

Добавить создание и редактирование рейсов с бизнес-валидацией связанных сущностей.

## Реализация

- [ ] Реализовать `POST /api/flights`.
- [ ] Реализовать `PUT /api/flights/{id}`.
- [ ] Создать `CreateFlightRequest`.
- [ ] Создать `UpdateFlightRequest`.
- [ ] Проверять существование аэропортов и самолёта.
- [ ] Проверять, что аэропорты вылета и прилёта различаются.
- [ ] Проверять, что время вылета раньше времени прилёта.
- [ ] Проверять вместимость нового самолёта.
- [ ] Вернуть `201 Created` при создании.

## Тесты

- [ ] Проверить успешное создание рейса.
- [ ] Проверить успешное изменение рейса.
- [ ] Проверить обязательные поля.
- [ ] Проверить несуществующие аэропорт и самолёт.
- [ ] Проверить одинаковые аэропорты.
- [ ] Проверить неверный порядок времени.
- [ ] Проверить недостаточную вместимость самолёта.
