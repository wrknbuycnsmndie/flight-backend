# F06: API создания и изменения рейсов

**Статус:** Выполнено

## Цель

Добавить создание и редактирование рейсов с бизнес-валидацией связанных сущностей.

## Реализация

- [x] Реализовать `POST /api/flights`.
- [x] Реализовать `PUT /api/flights/{id}`.
- [x] Создать `CreateFlightRequest`.
- [x] Создать `UpdateFlightRequest`.
- [x] Проверять существование аэропортов и самолёта.
- [x] Проверять, что аэропорты вылета и прилёта различаются.
- [x] Проверять, что время вылета раньше времени прилёта.
- [x] Проверять вместимость нового самолёта.
- [x] Вернуть `201 Created` при создании.

## Тесты

- [x] Проверить успешное создание рейса.
- [x] Проверить успешное изменение рейса.
- [x] Проверить обязательные поля.
- [x] Проверить несуществующие аэропорт и самолёт.
- [x] Проверить одинаковые аэропорты.
- [x] Проверить неверный порядок времени.
- [x] Проверить недостаточную вместимость самолёта.
