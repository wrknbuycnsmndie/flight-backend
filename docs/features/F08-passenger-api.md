# F08: API пассажиров

**Статус:** Запланировано

## Цель

Получать пассажиров рейса, добавлять новых пассажиров и удалять пассажиров.

## Реализация

- [ ] Реализовать `GET /api/flights/{flightId}/passengers`.
- [ ] Реализовать `POST /api/flights/{flightId}/passengers`.
- [ ] Реализовать `DELETE /api/passengers/{id}`.
- [ ] Создать `CreatePassengerRequest`.
- [ ] Создать `PassengerResponse`.
- [ ] Проверять существование рейса.
- [ ] Проверять уникальность номера паспорта.
- [ ] Запрещать превышение вместимости самолёта.

## Тесты

- [ ] Проверить получение пассажиров рейса.
- [ ] Проверить добавление пассажира.
- [ ] Проверить удаление пассажира.
- [ ] Проверить обязательные поля.
- [ ] Проверить дублирующийся паспорт.
- [ ] Проверить превышение вместимости.
- [ ] Проверить неизвестный рейс и пассажира.
