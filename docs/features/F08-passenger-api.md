# F08: API пассажиров

**Статус:** Выполнено

## Цель

Получать пассажиров рейса, добавлять новых пассажиров и удалять пассажиров.

## Реализация

- [x] Реализовать `GET /api/flights/{flightId}/passengers`.
- [x] Реализовать `POST /api/flights/{flightId}/passengers`.
- [x] Реализовать `DELETE /api/passengers/{id}`.
- [x] Создать `CreatePassengerRequest`.
- [x] Создать `PassengerResponse`.
- [x] Проверять существование рейса.
- [x] Проверять уникальность номера паспорта.
- [x] Запрещать превышение вместимости самолёта.
