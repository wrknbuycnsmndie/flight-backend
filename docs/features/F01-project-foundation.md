# F01: Проект и базовая конфигурация

**Статус:** Запланировано

## Цель

Подготовить приложение к запуску с Java 17, Spring Boot и настройками из переменных окружения.

## Реализация

- [ ] Проверить структуру Maven-проекта.
- [ ] Настроить подключение к PostgreSQL через переменные окружения.
- [ ] Установить `spring.jpa.hibernate.ddl-auto=validate`.
- [ ] Установить `spring.jpa.open-in-view=false`.
- [ ] Настроить базовый путь API `/api`.
- [ ] Добавить безопасные значения по умолчанию только для локальной разработки.

## Тесты

- [ ] Проверить запуск контекста приложения.
- [ ] Проверить загрузку конфигурации из переменных окружения.
