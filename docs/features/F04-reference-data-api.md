# F04: API справочников

**Статус:** Запланировано

## Цель

Предоставить frontend список аэропортов и самолётов для выбора при работе с рейсами.

## Реализация

- [ ] Реализовать `GET /api/airports`.
- [ ] Реализовать `GET /api/aircrafts`.
- [ ] Создать DTO `AirportResponse`.
- [ ] Создать DTO `AircraftResponse`.
- [ ] Добавить репозитории, сервисы и контроллеры.
- [ ] Не возвращать JPA-сущности напрямую.

## Тесты

- [ ] Проверить HTTP-статус `200 OK`.
- [ ] Проверить состав и формат DTO.
- [ ] Проверить пустой список без ошибки.
