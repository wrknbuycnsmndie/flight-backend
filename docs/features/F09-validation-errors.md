# F09: Валидация и обработка ошибок

**Статус:** Выполнено

## Цель

Возвращать единый стандартный формат ошибок и корректные HTTP-статусы для всех API.

## Реализация

- [x] Создать глобальный обработчик через `@RestControllerAdvice`.
- [x] Использовать `ProblemDetail` как стандартный формат RFC 9457.
- [x] Возвращать `application/problem+json`.
- [x] Расширить `ResponseEntityExceptionHandler` для стандартных MVC-ошибок.
- [x] Обработать ошибки Bean Validation для `@RequestBody`.
- [x] Обработать ошибки валидации параметров методов и query/path-параметров.
- [x] Создать отдельные исключения для случаев `404 Not Found`.
- [x] Создать отдельные исключения для бизнес-конфликтов `409 Conflict`.
- [x] Обработать ошибки нарушения ограничений базы данных.
- [x] Добавить в `ProblemDetail` HTTP-статус, заголовок, сообщение и путь запроса.
- [x] Добавлять подробности по отдельным полям только для ошибок валидации.
- [x] Не раскрывать SQL, stack trace и внутренние детали исключений клиенту.
- [x] Логировать неожиданные ошибки на сервере с полным stack trace.

## Тесты
