# F09: Валидация и обработка ошибок

**Статус:** Запланировано

## Цель

Возвращать единый стандартный формат ошибок и корректные HTTP-статусы для всех API.

## Реализация

- [ ] Создать глобальный обработчик через `@RestControllerAdvice`.
- [ ] Использовать `ProblemDetail` как стандартный формат RFC 9457.
- [ ] Возвращать `application/problem+json`.
- [ ] Расширить `ResponseEntityExceptionHandler` для стандартных MVC-ошибок.
- [ ] Обработать ошибки Bean Validation для `@RequestBody`.
- [ ] Обработать ошибки валидации параметров методов и query/path-параметров.
- [ ] Создать отдельные исключения для случаев `404 Not Found`.
- [ ] Создать отдельные исключения для бизнес-конфликтов `409 Conflict`.
- [ ] Обработать ошибки нарушения ограничений базы данных.
- [ ] Добавить в `ProblemDetail` HTTP-статус, заголовок, сообщение и путь запроса.
- [ ] Добавлять подробности по отдельным полям только для ошибок валидации.
- [ ] Не раскрывать SQL, stack trace и внутренние детали исключений клиенту.
- [ ] Логировать неожиданные ошибки на сервере с полным stack trace.

## Тесты

- [ ] Проверить единый формат `ProblemDetail`.
- [ ] Проверить ошибки валидации тела запроса.
- [ ] Проверить ошибки валидации query/path-параметров.
- [ ] Проверить `404 Not Found`.
- [ ] Проверить `409 Conflict`.
- [ ] Проверить нарушение уникальности номера паспорта.
- [ ] Проверить `500 Internal Server Error` для неожиданной ошибки.
- [ ] Проверить корректность пути запроса.
