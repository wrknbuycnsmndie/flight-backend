# F07: API удаления рейсов

**Статус:** Выполнено

## Цель

Удалять рейсы вместе с пассажирами, связанными с этим рейсом.

## Реализация

- [x] Реализовать `DELETE /api/flights/{id}`.
- [x] Проверять существование рейса.
- [x] Обеспечить каскадное удаление пассажиров.
- [x] Возвращать `204 No Content` при успешном удалении.

## Тесты

- [x] Проверить успешное удаление.
- [x] Проверить ответ для неизвестного рейса.
