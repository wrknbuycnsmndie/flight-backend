# F07: API удаления рейсов

**Статус:** Запланировано

## Цель

Удалять рейсы вместе с пассажирами, связанными с этим рейсом.

## Реализация

- [ ] Реализовать `DELETE /api/flights/{id}`.
- [ ] Проверять существование рейса.
- [ ] Обеспечить каскадное удаление пассажиров.
- [ ] Возвращать `204 No Content` при успешном удалении.

## Тесты

- [ ] Проверить успешное удаление.
- [ ] Проверить ответ для неизвестного рейса.
- [ ] Проверить удаление связанных пассажиров.
