# F05: API чтения рейсов

**Статус:** Запланировано

## Цель

Реализовать получение списка рейсов и подробной информации о рейсе.

## Реализация

- [ ] Реализовать `GET /api/flights`.
- [ ] Добавить пагинацию с размером страницы по умолчанию 10.
- [ ] Вернуть коды аэропортов в элементе списка.
- [ ] Вернуть количество пассажиров.
- [ ] Реализовать `GET /api/flights/{id}`.
- [ ] Вернуть подробные данные аэропортов и самолёта.
- [ ] Создать `FlightListItemResponse`.
- [ ] Создать `FlightDetailsResponse`.
- [ ] Создать общий `PageResponse<T>`.

## Тесты

- [ ] Проверить пагинацию и значение размера страницы по умолчанию.
- [ ] Проверить сортировку и количество элементов.
- [ ] Проверить маппинг аэропортов, самолёта и пассажиров.
- [ ] Проверить ответ `404 Not Found` для неизвестного рейса.
